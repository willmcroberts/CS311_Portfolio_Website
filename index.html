Steam Comparator

This was the first project I worked on with a group of other students, during my third semester at Ball State. The program uses the Steam API to pull information about users' games and hours played, ordering the games by hours played. The program alsos you to put two Steam users' information side by side, so you can compare your hours played with a friend. The program was written in Java, and uses the Swing library for the GUI.

This porject uses the minimax algorithm to create an agent that can play Connect Four. The agent is able to play against a human player, and can also play against another agent. The program was written in python, and uses the Tkinter library for the GUI.
